# 智慧模型卡模板

产出档案时严格按此结构与颗粒度。`<>` 为占位。正文用中文；原著引文保持原文，后跟一句话白话释义。第 2/3/4 节条目用 `**N）名称**` 编号，供应用协议以『第 X 节第 N 条』回溯引用；快速请教时的内联轻量卡也按同样节次结构编号后再引用。

# <人物名> 智慧蒸馏档案

> 蒸馏时间：<YYYY-MM-DD> ｜ 素材来源：<自身知识 / 联网检索 / 用户文档名> ｜ 可信度：<高/中/低 + 一句话说明（史料丰富度、引文核实程度）>

## 1. 人物速览

<一段话 80-150 字：身份、时代、核心成就、他解决过什么大问题、为什么今天值得请教他。>

## 2. 世界观内核（3-5 条）

他对世界的基本判断，是整个模型的地基。每条格式：

- **<四~八字原则名>**
  - 内涵：<2-3 句，说清他相信什么>
  - 原文/史据：「<原文>」——《<出处>》；或 <一段史实概述并注明史源>
  - 现代转译：<这条信念在今天对应什么，1 句>

## 3. 决策启发式（5-8 条）

可执行的 if-then 规则，全部从史实归纳，禁止虚构：

- **<触发情境> → <他会怎么做>**
  - 史据：<哪段经历体现>
  - 对应世界观：第 2 节第 N 条

## 4. 思维盲区与失败模式（2-4 条）

- **<盲区名>**
  - 史实：<他为此栽过的跟头>
  - 现代警示：<照搬此模型的人会在哪类问题上翻车>

## 5. 关键经历索引（3-5 段）

每段 100 字左右：事件 → 他的选择 → 揭示的原则（标注对应第 2/3 节条目编号）。这一节是模型的证据库，应用分析时回溯到这里。

## 6. 金句库

按主题分组。每条：原文 ｜ 出处 ｜ 真实性（确证/存疑/伪托）｜ 适用场景。真实性无法核实的标「存疑」；确认伪托的保留并明确标注，防止用户将来引用翻车。真实性判定后可跟一句核实途径的附注（如「确证·自述见现代著作转引，一手篇目未核」），覆盖介于确证与存疑之间的中间情况。

## 7. 适用边界

- 擅长：<3-5 类现代问题>
- 不擅长：<2-4 类，说明为什么>
- 时代局限：<一句话声明哪些现代语境超出他经验的解释范围>

## 填写示例（节选自「苏轼」档案，仅示范格式与颗粒度，不要求写这么多）

### 2. 世界观内核（节选）

- **随处安顿**
  - 内涵：环境不由人选，但人可以在任何处境里重建生活支点；安顿不是认命，是换一块土壤重新扎根。
  - 原文/史据：「此心安处是吾乡」——《定风波·南海归赠王定国侍人寓娘》（意为：内心安定之处便是故乡）；贬黄州期间开垦东坡、筑雪堂。
  - 现代转译：外部环境不可控时，把注意力从"我在哪"移到"我能建什么"。

### 3. 决策启发式（节选）

- **遭遇重大挫败 → 先降预期、再建支点**：不与挫败缠斗，先把生活降到可维持的水平，再从最擅长的事里重建掌控感。
  - 史据：乌台诗案下狱百余日，贬黄州后俸禄断绝，开荒东坡自耕，同时写出一生高峰之作。
  - 对应世界观：第 2 节·随处安顿。

### 4. 思维盲区（节选）

- **口舌之快压不过风险计算**：诗文讥讽朝政一时痛快，但信息会留存、会流传、会被解读。
  - 史实：乌台诗案因诗文获罪，下狱几乎丧命，被贬黄州。
  - 现代警示：在一切表达皆留痕、可转发的环境里，讽刺性表达有长尾风险；此模型在这一处不可照搬。
