# 选题引擎（生成启发法与标注体系）

> content-planner 的生成内核。素材来自四流派蒸馏（`ai-director/references/多流派蒸馏.md`）中的共识部分，标注体系为本技能包原创。

## 六条生成启发法

1. **选题公式**（流派三，方片51）：猎奇 × 反差大 × 文化结合——三者占一即达标，占二以上"80-90% 会爆"。
2. **热点三切口**（流派一）：角色代入（这事里"我"是谁）/ 行为代入（我会怎么做）/ 事件→影响→反思。追热点的目的不是蹭流量，是借事件锚定人群。
3. **需求下挖**（流派一）：沿一个现象向下问，从不同现象提炼同一个本质——现象是素材，本质才是选题。
4. **选题池**（流派一/三）：自己视频的评论区 + 私信 + 同行评论区的高赞问题。用户主动问出来的问题 = 共情半径已被验证的选题。
5. **大共情域兜底**（流派四）：人际 / 职场 / 情感 / 成长 / 金钱五个域永远有半径；小众专业内容必须"翻译"进大共情域才有流量上限（如"XX 工具"→"普通人怎么用它翻身/省时间"）。
6. **解决问题 > 制造情绪**（流派一/二）：情绪只做钩子不做主菜；赛道长期价值看"能否变现、能否复购"，不看我当下爽不爽。

## 四指标 × 选题角度（按流派一的"版本答案"框架）

| 主打指标 | 选题角度 | 举例句式 |
|---|---|---|
| **收藏** | 清单 / 避坑 / 教程 / 资源盘点 / 保姆级攻略 | "做 XX 之前先看这篇""XX 全流程" |
| **推荐** | 共同记忆 / 争议观点 / 身份认同站队 | "XX 是骗局""真正 XX 的人都在……" |
| **追更** | 连续进度 / 挑战进度 / 原创世界观 | "第 N 集""挑战第 X 天""更新到 XX 了" |
| **社区** | 交作业 / 投票 / 共创 / 评论区能吵起来 | "评论区交作业""你们选哪个""接着我的来" |

## 系列三型（系列设计的类型学）

- **提升型**：用户看完变强（教程/攻略/认知升级）——撑收藏，账号的"产品目录"。
- **挑战型**：博主自己下场做一件事（挑战 X 天 / 从 0 起 Y 号）——撑追更，天然有进度感和未完待续。
- **剧情型**：有人设和叙事的内容（情景/访谈/纪实）——撑推荐和记忆点，成本最高，适合有搭档或故事库存时开。

## 标注体系定义（选题表五列的口径）

- **钩子角度**：反常识断言 ｜ 亏欠感/好奇 ｜ 挑衅互动 ｜ 风向解读 ｜ 数字门槛 ｜ 用户认领（详见流派一钩子库）
- **共情半径**：大（跨圈层，五个大共情域内）/ 中（垂类内）/ 小（核心粉向，慎用）
- **价值类型**：实用（能照做）/ 认知（换看法）/ 情绪（被说中）/ 身份认同（这是我）

## 自检清单（选题表交付前过一遍）

- [ ] 每条能一句话回答"用户看完带走什么"
- [ ] 干货类选题都带"我"的用法或下场
- [ ] 大共情域选题 ≥ 1/3
- [ ] 追更型选题挂了编号或进度感
- [ ] 没有"纯蹭热点无自己角度"的条目
- [ ] 收藏型 : 推荐型 ≈ 6:4（起号期偏收藏，符合平台 2026 价值导向）
