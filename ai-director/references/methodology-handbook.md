## 卷首 · 四条公理

他的所有内容都从这四句话推出来，先背这个：

1. **自媒体的本质是"ta 媒体"**——不是表达你自己，是替"ta"（用户）做内容。一切从用户需求出发，不从"我想说什么"出发。
2. **爆款的本质是共情**——选题要锚定"最多人能够共情的东西"，链接多少人，流量上限就是多少。
3. **低粉高赞 > 粉丝量**——不追求涨粉数字，追求赞粉比。每条视频都是专业度的证据，作品列表就是销售页。
4. **免费放出付费内容，换取流量**——把本来要卖的东西直接讲出来，干货本身就是钩子。

## 第一章 · 平台风向（2026 年版）

这是他 9 月两条高赞视频（创作者大会解析 + 版本答案）的核心，相当于他的"考试大纲"：

### 1.1 逻辑变了：从"抓眼球"到"抓价值"
- 2026 年 5 月新规改变流量分配，平台转向**深度有价值的内容**。
- 算法精准化："**推给懂的人和需要的人**"——**精准流量打法已死**，别再想"骗一批泛流量"，要服务好精准人群。
- "精选"流量池扶持**中长视频**：价值感、获得感、信息密度、干货攻略。
- 20 分钟以上视频，收藏概率显著更高。

### 1.2 四大互动指标（他的"版本答案"框架）
互动指标从点赞评论变为：**收藏、推荐、追更、社区**。每一条都有对应的做法：

| 指标 | 平台在奖励什么 | 内容怎么做 |
|---|---|---|
| **收藏** | 用户"觉得有用想再看一遍" | 从用户出发、解决真实痛点、简单易懂、实操落地、细致深入、文本画面简洁、分段式有逻辑 |
| **推荐** | 用户愿意转发给别人 | 回归生活感受、链接最大的人类共同情感记忆、大叙事或小细腻、观点鲜明、氛围烘托、场景/情节/人物、BGM |
| **追更** | 用户等着你更新 | 原创世界观、系列化可延展、风格新颖、人物 IP 鲜明、视觉+语言的 slogan、未完待续感 |
| **社区** | 用户和同行围绕你动起来 | 造梗空间、归属感、让用户动起来（评论区交作业、发视频、共创、接力） |

### 1.3 创作者大会关键词
- **三大指标**：推荐、收藏、追更（对应共情、实用、系列化）。
- **两大优质**：优质作者、优质内容（优质作者推流时间更长）。
- **三大新**：新面孔（扶持新创作者）、新标杆（成熟作者代表作）、新赛道（AI 原生创作）。
- **知识博主五要素**：真探（真实探索）、知识获得感、幽默、立体真实（允许不完美）、现场感。

## 第二章 · 选题：共情半径决定流量上限

### 2.1 选题的唯一定律
> 流量天花板 = 这个选题能链接多少人 × 共情强度

- **兴趣强度决定停留，链接人数决定上限。**
- 1000 万播放是他给出的个人天花板：亿级播放=优质内容+广泛传播，千万级=有特色有吸引力，百万级=有知识有技巧。先想清楚自己要哪一级。

### 2.2 挖选题的方法
1. **沿需求向下挖**：从一个现象往下问，从不同现象里提炼同一个本质。
2. **热点找选题三切口**：角色代入（这事里"我"是谁）、行为代入（我会怎么做）、事件→影响→反思。
3. **评论区/私信当选题池**：答疑即内容（他的"编导在线答疑"系列，1.4 万赞），用户的问题就是最精准的选题。
4. **选"解决问题"，不选"制造情绪"**：他说情绪赛道娱乐赛道不赚钱，解决问题的赛道才有生意。

### 2.3 赛道地图（他给的全景）
- 口播 / 非口播两大类，选赛道结合自身优势。
- **Vlog 赛道最卷；颜值赛道商业空间最大；娱乐赛道最不赚钱；短片、AIGC、微综艺是蓝海。**
- 商业空间先看"视频里能不能自然植入"：能出产品、能出场景的内容才有广告商预算。
- 平台差异：**小红书涨粉比抖音容易**（如果定位是编导/干货型，先做小红书）。

## 第三章 · 内容：信息密度是唯一的硬通货

### 3.1 百万爆款的必要条件（四条全占才做）
1. 用户**理解成本低**（听懂不需要智商门槛）
2. **链接群体大**（共情半径）
3. **满足用户需求**（好奇、陪伴、造梦 / 共情、猎奇、得到）
4. **具有互动性**（能引发收藏/转发/交作业）

### 3.2 爆款三类型
- **万古同悲型**：踩中人类共同情感记忆（时代、童年、集体情绪）※注释为推断
- **惊世骇俗型**：强预期违背，颠覆认知
- **打破节奏型**：打破平台同质化的内容节奏

### 3.3 信息密度定律（他最出圈的答疑，1.4 万赞）
- 密度低的定义：**"用两句废话解释一句听不懂的话。"**
- 修改方向：难懂的话 → 用简单直白的方式重新说一遍；删掉所有过渡废话。
- 反面警告：**别"太干巴"**——干货太硬会把人群框定出去，"别对观众的智商有要求"，也别对观众有知识预设。
- 数据不好的视频别删，**做成合集**；每天稳定更新数据好的内容方向。

### 3.4 完播率五法（"用户点开你视频那一刻，你就开始欠他的了"）
1. **制造信息缺口**：让用户知道自己在等什么。
2. **提供中间回报**：中段给新判断依据、用案例证明区别、告诉用户下一步做什么。
3. **降低认知负荷**：绕开"知识诅咒"，复杂知识说成人话。
4. **利用生成效应**：让用户参与（投票、选择题、评论区作业），产生沉没成本。
5. **营造进度感**：让用户知道离答案还有多远；提高信息密度、缩短时长。

### 3.5 前两秒的脑科学（"给我两秒就好"）
- **用户认领**：用难以量化的好特质锚定人群（"真正想做内容的人……"），制造预期违背的痛点，让用户产生正向身份认同。
- **观者效应**：让用户觉得"这视频和我有关"，才会优先处理你的信息。
- **预期违背**：打破用户预测，激发好奇。
- **合意难度**：让用户"踮脚可得"——太简单没意思，太难就划走。
- **兴趣强度 × 链接人数** = 停留 × 上限。

### 3.6 爆款没有用，爆款系列才有用
- 单条爆款是彩票，**系列才是资产**。
- 爆款视频两种来源：原创（人设、外表、人格魅力、攻略）、跟热点（跟热点也必须展现人设）。
- 爆款系列三种：**剧情系列、提升系列、挑战系列**——用未完结的叙事或数字（第 N 期）给出延续感。
- 爆款之后：**复制爆款，直到爆款无用**，再开新系列。
- 维持更新：**同时跑两个以上系列**，互相接力不断更。
- Tag 策略：身份/赛道 tag + 官方活动 tag。
- 善用搜索流量（干货内容的二次分发渠道）。

## 第四章 · 人设与 IP：记忆点 > 露脸

### 4.1 他自己的答案
不露脸也能做，**"露脸是为了让人记住，头套可以一直戴，只要有记忆点就行"**——他戴 Spider-Man 头套 + 白板写板书拍口播。头套=视觉锤，白板=信息密度道具。

### 4.2 IP 的构成
- **IP = 真实 + 设计**：真实是你本来有的，设计是放大记忆点的包装，但**设计人设不能颠覆真实**。
- 打造 IP 四件套（vlog 视角）：**刻板行为**（固定动作/口头禅）、**作风**（行事风格）、**个人风格**、**立体展示**（多面性，别只有一面）。
- 视觉 + 语言的 slogan：看到什么/听到什么就知道是你。

### 4.3 创始人/企业 IP
- 博主做 IP：增强粉丝粘性、提高种草力。
- 企业主做 IP：**降低用户决策成本**、反映企业文化；两种目标——品牌影响力 / 直接转化；两种形式——口播或拍日常。

## 第五章 · 生产 SOP（他自己的流水线）

1. **建立选题库**（常备，不靠灵感）。
2. **不写逐字稿，写板书**：白板上把框架写出来，照着框架讲——天然结构化、天然信息密度。
3. 拍完**立刻剪**，不隔夜。
4. 剪辑四步：板书拍摄 → 剪辑 → 配字幕 → 选 BGM。
5. 视频长度：**2 分钟以上的深度口播干货**（符合平台对"价值内容"的扶持方向）。
6. 发布时间有讲究（选目标用户活跃时段）。
7. 节奏参考：他 7 月起号期几乎日更（10 条作品拿走 8 万+赞），9 月配合线下课招生再度加密更新。
8. 持续输入：流量上不来先怀疑内容质量，内容上不去先怀疑**自己的输入量**——推荐算法是精准的，它只是如实反馈你内容的价值。

## 第六章 · 变现：生意 = 产品 + 渠道 + 广告

### 6.1 找产品
- 自媒体平台已经替你解决了渠道和广告，你只需要**产品**。
- **向外找**：赚风口周边的钱——理解风口人群的客户需求，提供相关服务（他自己的产品就是"教别人做自媒体"）。
- **向内找**：用"消费型兴趣"赚钱，把自己花钱的兴趣转化为产品。
- 产品决定内容形态：**服务型 → 拍 vlog（过程展示）；资料型/知识型 → 拍口播干货或图文。**

### 6.2 变现时机
- **爆款系列的涨粉期不要接广告**；系列生命周期约 **3-6 个月**，进入倦怠期或账号到几十万体量再接。
- 接单要评估客户：经济实力、内容能力，**别接注定火不了的单**（砸自己招牌）。

### 6.3 他的漏斗（可直接抄结构）
作品立人设（低粉高赞=证据）→ 昵称挂课（"10月上海线下课"，按期更换制造紧迫感）→ 简介挂"咨询" → 私信筛选 → 线下课/IP 孵化。
配套人设动作：公开骂洗稿、骂 AI 低质搬运，立"真编导"标签。

## 附录 C · 直接可以抄的 6 个动作

1. 把你的每条经验压缩成"**三词一组**"的口诀再讲。
2. 开头两秒用"**用户认领 + 预期违背**"（先圈人，再打破他的预期）。
3. 全程自检：**有没有用两句废话解释一句听不懂的话**？有就删。
4. 内容按**收藏**设计（实操、可回看），账号按**系列**设计（可追更），评论区按**社区**设计（交作业、造梗）。
5. 找一个**头套级别的记忆点**——不露脸也能立住人设。
6. 账号当销售页用：每条视频都是证据，昵称/简介留转化钩子。
